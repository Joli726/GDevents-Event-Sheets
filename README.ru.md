# GDevents

[English](README.md) · **Русский**

Листы событий в стиле GDevelop для **Godot 4.7**. Логика игры собирается
из условий и действий, а не пишется кодом; листы компилируются в обычный
читаемый GDScript без интерпретатора в игре.

- **Редактор листов событий** прямо в Godot: условия, действия, подсобытия,
  циклы, группы, события «ИЛИ», локальные переменные, общие листы, свои
  функции из событий, отладка во время игры, поиск и замена, перетаскивание, отмена, ошибки видны прямо на строке, а ошибка в
  игре называет событие, из которого пришла.
- **Выборка объектов как в GDevelop**: «Bullet сталкивается с Enemy →
  Удалить Bullet» удаляет ровно те пули, что попали.
- **34 готовых поведения** — персонаж платформера с лестницами, патрульный
  враг, поиск пути, самонаводящиеся ракеты, машины, движущиеся и рушащиеся
  платформы, чекпоинты, комбо ближнего боя, способности, состояния, полоски
  здоровья, диалоги, «сочность» и другие — с окном настроек, пресетами и
  просмотром кода.
- **244 инструкции**: касания, срабатывающие один раз, «подождать N
  секунд», таймеры объектов, геймпад, эффекты, списки и многое другое.
- **Свои поведения и расширения**: один файл `.gd` с несколькими метками в
  комментариях даёт новые условия, действия и выражения. Встроенное поведение
  можно скопировать и изменить — с версиями и возвратом к исходному.
- **Проверка сцен и файлов**: проблемы объясняются простыми словами, есть
  кнопки исправления.
- **Интерфейс на английском и русском**: язык выбирается при первом запуске
  и меняется в любой момент.
- **Удобно работать с нейросетями**: руководство для авторов, `AGENTS.md`,
  скилл для Claude Code и проверка одной командой, что файл работает.

## Установка

1. Скопируйте папку `addons/gdevents` в папку `addons/` своего проекта.
2. В Godot: **Проект → Настройки проекта → Плагины**, включите **GDevents**.
3. Выберите язык интерфейса в появившемся окне. Рядом с 2D / 3D / Script
   появится вкладка **«События»**.

## Быстрый старт

1. На вкладке **«События»** нажмите кнопку нового листа рядом со списком
   листов.
2. Откройте **«Объекты»**, добавьте сцены, из которых состоит игра, и дайте
   им поведения — например, «Персонаж платформера» игроку.
3. Нажмите **«Добавить событие»**, а внутри события — **«+ Условие»** и
   **«+ Действие»**.
4. Нажмите **«Привязать к сцене…»**, выберите сцену уровня и запускайте
   игру — лист сохранится и соберётся сам.

## Проверка своих файлов

```bash
godot --headless --quit-after 5000 res://addons/gdevents/tools/check.tscn -- res://behaviors/my_behavior/my_behavior.gd
```

Без пути проверяются все свои поведения, расширения и листы.
